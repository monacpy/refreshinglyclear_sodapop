# Soda Premium Project

This project follows the premium website workflow you outlined:

## Stack
- Next.js + React for the frontend shell
- GSAP for animation timing and motion polish
- Lenis for smooth scrolling behavior
- Three.js / R3F for future 3D scene expansion
- Supabase / Neon as the data layer depending on stage

## Workflow used
1. Collect references and define the visual direction.
2. Assemble the stack intentionally instead of installing everything at once.
3. Build the landing page in structure-first stages.
4. Add motion and polished interactions only after the core skeleton is stable.
5. Reuse premium components and style systems rather than re-creating them from scratch.
6. Add only the backend needed for the actual product requirements.

## Run locally
1. Install Node.js and npm
2. Run `npm install`
3. Run `npm run dev`
4. Visit `http://localhost:3000`

## Notes
The current version is a premium one-page landing experience with a dark, glassy UI, strong headline hierarchy, motion cues, and a product-style hero treatment.
